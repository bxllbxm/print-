# LAYA 인쇄 점검 — Adobe 앱 내 실행 도구

길벗의 8가지 인쇄 유의사항을 기준으로 현재 열린 InDesign·Illustrator 원본을 읽고, 점검 창과 TXT 보고서를 제공합니다. Codex, LAYA 실행, Python 또는 터미널 명령은 필요 없습니다. 독립적인 Adobe 스크립트입니다.

## Illustrator에서 실행

1. 점검할 문서를 엽니다.
2. **파일 → 스크립트 → 기타 스크립트…**를 선택합니다.
3. 이 폴더의 **LAYA 인쇄 점검.jsx** 파일명을 클릭해 선택한 뒤 **열기**를 누릅니다. 폴더로 이동한 것만으로는 파일이 선택되지 않을 수 있습니다. 같은 내용의 `.js` 파일도 함께 제공합니다.
4. 인쇄소 기준을 입력하고 **점검 시작**을 누릅니다.
5. 항목을 선택하면 상세 설명을 볼 수 있습니다. **보고서 저장**으로 TXT를 저장할 수 있습니다.

메뉴에 고정하려면 `LAYA 인쇄 점검.jsx` 또는 `.js` 중 한 파일만 Illustrator의 언어별 스크립트 폴더에 복사한 뒤 앱을 다시 시작합니다. 이 Mac의 폴더는 `/Applications/Adobe Illustrator 2026/Presets.localized/ko_KR/스크립트`이며 관리자 권한이 필요할 수 있습니다. 저장하지 않은 작업이 있으면 먼저 저장합니다.

## InDesign에서 실행

1. **창 → 유틸리티 → 스크립트**를 엽니다.
2. **사용자**를 더블클릭해 펼친 뒤 **LAYA 인쇄 점검.jsx**를 더블클릭합니다.
3. 기준을 입력하고 **점검 시작**을 누릅니다.

다른 컴퓨터에서는 `LAYA 인쇄 점검.jsx` 한 파일을 InDesign 사용자 스크립트 폴더에 복사합니다. macOS 경로는 `~/Library/Preferences/Adobe InDesign/[버전]/[언어]/Scripts/Scripts Panel`입니다. 스크립트 패널에서 사용자 폴더를 우클릭해 Finder에서 표시하면 실제 경로를 찾을 수 있습니다.

## 기준 입력

- 안전 여백은 기본 3mm입니다. 원문의 3–5mm 범위와 인쇄소 요구에 따라 바꿉니다.
- 최소 이미지 해상도는 기본 300PPI입니다. 실제 최종 배치의 해상도 기준입니다.
- 도련 폭과 작은 글자 pt 경계는 원문에 숫자가 없으므로 빈칸입니다. 인쇄소 요구가 있을 때 입력합니다.
- 의도된 별색에는 인쇄소와 합의한 잉크·후가공 별색의 정확한 이름을 쉼표로 구분해 입력합니다.
- PDF 외 낱장 표지·명함 원본 납품일 때만 해당 납품 방식을 선택합니다.

## 자동 점검의 범위

| 항목 | 제공하는 근거와 추가 확인 |
| --- | --- |
| 재단 안전 여백 | 글자 프레임 경계의 후보 거리. 실제 글자·로고 외곽과 중요도는 직접 확인. |
| 도련 | InDesign 도련 설정과 입력된 기준 비교. 실제 배경 채움과 Illustrator 도련은 추가 확인. |
| 테두리 | 재단 주변 직사각형 테두리 후보의 3mm 두께 권고. 모든 선에 적용하지 않음. |
| 작은 글자 | 실제 글자 잉크·틴트와 사용자 pt 경계, K≤10의 옅은 글자 후보. 검정 의도와 최종 분판은 확인. |
| 리치블랙 | K100과 유색 잉크가 혼합된 글자 후보. 건조·뒷묻음·페이지 색 차이는 인쇄소 확인. |
| 글꼴 | InDesign 폰트 상태·포함 허용, 원본 납품의 편집 가능한 글자. 최종 PDF 포함 및 Illustrator 폰트 대체는 추가 확인. |
| 이미지 | InDesign에서 읽을 수 있는 이미지 유효 PPI·색 공간. Illustrator 유효 PPI와 포함 PDF/EPS 내부는 미확인. |
| 별색·RGB | 실제 글자·일부 경로 색상과 별색 견본. 견본 존재만으로 실제 사용을 확정하지 않음. |

‘확인됨’은 수집된 근거에만 해당합니다. 전체 파일의 인쇄 적합성, PDF/X 인증, 최종 PDF의 글꼴 포함·분판·도련 채움은 별도 확인합니다. 읽지 못한 객체, 숨김·비인쇄 객체, 마스터, 패턴·그라디언트·효과, 표·각주, 검사량 제한은 ‘추가 점검’에 표시합니다.

현재 버전은 Adobe 안에서 창으로 실행하는 **스크립트형 도구**입니다. 도킹 가능한 정식 플러그인 패널은 아닙니다. 원본 자동 수정과 외부 전송은 수행하지 않습니다. 보고서는 사용자가 선택한 TXT에만 저장합니다.

## 현재 검증 상태

자동 테스트 64개(규칙 18개, InDesign 수집 25개, Illustrator 수집 21개)가 통과했습니다. 테스트는 원본을 변경하지 않는 조건, 오인하기 쉬운 잉크·도련·글꼴 규칙과 읽지 못한 범위의 표시를 검증합니다. InDesign 사용자 폴더에 실행 파일을 등록했습니다.

2026년 10월 10일, InDesign 2026과 Illustrator 2026에서 실제 설정 창과 8개 항목의 결과 창이 열리는 것을 확인했습니다. InDesign 시험 문서에서는 재단선과 0.68mm 떨어진 글자 프레임 후보에 ‘주의’를 표시했고, TXT 보고서 저장도 확인했습니다. Illustrator에서는 현재 열린 문서를 읽어 결과 창을 표시했습니다. 이는 앱 내 실행 확인이며 최종 인쇄 파일의 적합성 인증은 아닙니다.

## 공유

다른 사람에게 이 폴더의 ZIP을 전달하면 됩니다. 실행에는 `LAYA 인쇄 점검.js` 또는 `.jsx` 한 파일과 Adobe 앱만 있으면 됩니다. 실행 파일에는 개인 경로나 사용자 문서가 포함되지 않습니다. Adobe 2026에서 확인 대상으로 준비했으며 다른 버전은 실행 확인이 필요합니다.
