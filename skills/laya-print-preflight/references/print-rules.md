# 출처와 8가지 판정 기준

출처: 길벗, [인쇄할 때 꼭 알아야 하는 주의사항 8가지!!](https://blog.naver.com/gilbutzigy/223785925614). 화면 표시 게시일 2018-09-17 13:11, 확인일 2026-10-10. 아래는 주의사항 부분을 재구성한 요약이다. 인쇄소와 상의할 항목이 있다는 원문의 맥락을 유지한다.

| 번호 | 원문 기준 요약 | 검사 적용 범위 |
| --- | --- | --- |
| 1 | 중요 글자·로고는 재단선 안쪽 3–5mm. 재단 밀림은 1–2mm 발생 가능. | 중요 객체 전체의 재단선까지 거리. |
| 2 | 배경·전면 그래픽을 재단 밖 작업선까지 연장. | 실제 채움 범위. 도련 폭 숫자는 미지정. |
| 3 | 재단 주변 테두리는 3mm 이상 두께 권고. | 외곽 테두리에 한정. 모든 선의 기준 아님. |
| 4 | 작은 검정 글자는 K100, 회색은 K 농도 사용. K≤10%의 작은·얇은 글자는 선명도 주의. | 원본/분판의 실제 잉크값. 작은 글자의 pt 경계는 미지정. |
| 5 | 리치블랙은 작은 글자 핀 어긋남, 페이지 색 차이, 건조·뒷묻음 주의. | C30/K100은 예시이며 표준 배합 아님. |
| 6 | PDF로 보내지 않는 낱장 표지·명함은 글자 윤곽선 권고. | 모든 PDF의 일괄 아웃라인 요구 아님. |
| 7 | 삽입 이미지는 CMYK·300dpi로 준비하고 RGB 변환 여부 확인. | 최종 배치의 유효 PPI도 확인. |
| 8 | 의도하지 않은 별색을 CMYK로 변환하고 변환 뒤 색상 확인. | 의도된 별색은 인쇄소 요구대로 보존. |

## 자동 검사와 추가 확인의 경계

이 구분은 원문에 없는 구현상의 판단이다.

| 번호 | 자동 도구가 제공하는 근거 | 판정에 추가로 필요한 근거 |
| --- | --- | --- |
| 1 | 페이지 박스와 크기 | 재단 위치 확정, 글자·아웃라인·로고의 실제 위치 |
| 2 | 명시된 도련·재단 박스의 기하 비교 | 배경이 작업선까지 채워짐을 시각·원본 확인 |
| 3 | 자동 판정하지 않음 | 재단 주변 테두리 식별 및 최종 물리 두께 측정 |
| 4 | 발견한 색 공간·색 설정 후보 | 작은 글자의 C/M/Y/K 값, 변환/분판 결과 |
| 5 | 발견된 CMYK 색 설정 후보(리치블랙 판정 아님) | 실제 배합·작은 글자 사용 여부, 인쇄소의 잉크·건조 기준/교정쇄 |
| 6 | 폰트 자원과 포함 상태 | PDF 외 낱장 원본의 윤곽선 여부, PDF 렌더링 |
| 7 | 검출된 이미지 배치의 해상도·색 공간 | 미지원 객체, 마스크, 재표본화·최종 출력 사양 |
| 8 | 발견된 RGB·별색 자원과 연산자 후보 | 의도된 별색 목록, 잉크 분판, 변환 후 시각 비교 |

전체 파일의 RGB/별색 부재, 총 잉크량, PDF/X 적합성, 글자별 잉크값은 이 보조 도구로 인증하지 않는다. CMYK 출력 의도/프리셋만으로 객체의 CMYK 변환을 증명하지 않는다. 색상·후가공용 별색·재단선의 의도는 작업 사양에서 확인한다.

거리와 획 두께는 화면 확대율이 아닌 최종 출력 크기에서 측정한다. 1mm는 약 2.835pt, 3mm는 약 8.504pt이다. 객체의 확대·축소도 반영한다. PDF의 DeviceGray만으로 실제 분판이 K 단색임을 보증하지 않는다.

## 현재 앱의 점검 근거

다음 공식 문서는 앱 점검·내보내기 방법을 보충한다. 블로그의 숫자 기준과 구분한다.

- [Adobe InDesign Preflight](https://helpx.adobe.com/indesign/desktop/print/preflight/configure-and-use-the-preflight-panel.html): 누락 폰트·링크, 넘친 텍스트, 낮은 이미지 해상도 등을 프로파일로 확인.
- [Adobe InDesign PDF 내보내기 옵션](https://helpx.adobe.com/indesign/desktop/save-export-and-publish/save-and-export/adobe-pdf-export-options.html): 도련, 색상 변환·출력 의도, 폰트 포함 설정.
- [Adobe Illustrator PDF 옵션](https://helpx.adobe.com/illustrator/using/pdf-options.html): 도련과 색상·프로파일 및 폰트 내보내기 설정.

메뉴 이름은 앱 버전과 언어에 따라 현재 화면에서 확인한다. PDF/X를 요구받은 경우 Acrobat 등 해당 표준을 검증하는 도구로 따로 검사한다.
